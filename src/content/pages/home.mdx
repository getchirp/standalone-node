# Your Astro content. A better way to edit it.

Chirp adds a visual Markdown and mdx editor to the project you already have. It runs locally, reads your existing content collections, and writes changes back to the same files.

The page narrative and the structured product blocks belong to this document. The public homepage keeps the document as its source of truth while the editor supplies the visual interface.
